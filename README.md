# Практическая работа № 3

## «Фоновые изображения в CSS: Сэндвич-оформление блоков»

**Тема:** Применение CSS для работы с фоновыми изображениями, позиционирование графических элементов и управление слоями.

**Цель:** Научиться верстать декоративные текстовые контейнеры с использованием независимых фоновых изображений (шапка, растягиваемая по вертикали середина, подвал), управлять их повторением и позиционированием.

**Задача:** используя возможности CSS расположить на веб-странице по образцу  текст, заголовки и графические изображения.

## 🔒 Защита от плагиата (Индивидуальные параметры)

1. **Именной файл фона:** 
   Зайдите в папку `images/` и переименуйте файл фона середины блока `telo.gif`, назвав его **своей фамилией на латинице в нижнем регистре** (например: `ivanov.gif`). В файле стилей подключайте именно его.

   Значение красной строки (`text-indent`) для абзацев внутри блока рассчитывается индивидуально: **количество букв в вашей фамилии на латинице + 5%**.

## 📝 Обязательные технические требования

* **HTML-разметка:** Использование семантических тегов (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`). Запрещено использовать несемантические `<div>` вместо структурных разделов. На странице должен быть строго один заголовок `<h1>`, минимум два `<h2>` и списки.
* **Стилизация фона (CSS):** Все свойства фона описываются во внешней таблице стилей. Для сборки текстового блока примените три разных графических фрагмента (`verh.gif`, ваш именной файл фона, `niz.gif`), управляя свойствами `background-repeat` и `background-position`.
* **Оптимизация:** Для всех изображений, находящихся ниже первого экрана, обязательно должен быть прописан атрибут `loading="lazy"`.
* **Валидация:** Полное отсутствие ошибок и предупреждений при проверке кода в W3C Validator.
* **История разработки:** Наличие не менее 4–5 осмысленных коммитов, сделанных из среды разработки VS Code в процессе выполнения задачи.
