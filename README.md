## «Фоновые изображения в CSS: Сэндвич-оформление блоков»

**Тема:** Применение CSS для работы с фоновыми изображениями, позиционирование графических элементов и управление слоями.

**Цель:** Научиться верстать декоративные текстовые контейнеры с использованием независимых фоновых изображений (шапка, растягиваемая по вертикали середина, подвал), управлять их повторением и позиционированием.

**Задача:** используя возможности CSS расположить на веб-странице по образцу  текст, заголовки и графические изображения.

## 🔒 Защита от плагиата (Индивидуальные параметры)

Для успешной сдачи работы **каждый студент обязан настроить проект под себя**:

1. **Именной файл фона:** 
   Переименуйте файл фона середины блока `telo.gif` в корневой папке `images/`, назвав его **своей фамилией на латинице в нижнем регистре** (например: `ivanov.gif`). В файле стилей подключайте именно его из папки верхнего уровня: `background: url(../../images/ваша_фамилия.gif) repeat-y left top;`.
2. **Именной заголовок:**
   Текст внутри тега `<h2>` вашего декоративного блока должен строго соответствовать формату: `[Ваша Фамилия] | Блоки`.
3. **Динамический отступ (text-indent):**
   Значение красной строки (`text-indent`) для классов `.b2` и `.b3` рассчитывается индивидуально: **количество букв в вашей фамилии на латинице + 5%**.
   * *Пример для фамилии Ivanov (6 букв): 6 + 5 = 11%. Ваше свойство: `text-indent: 11%;`*

## 📝 Обязательные технические требования

* **HTML-разметка:** Создание структуры внутри обертки `<div>` с классом `.bl` согласно условию задачи (заголовок `<h2>` и три абзаца с соответствующими классами `.b2` и `.b3`).
* **Стилизация фонов (CSS):** Все свойства описываются во внешней таблице стилей. Для сборки текстового блока примените три разных графических фрагмента (`verh.gif`, ваш именной файл фона, `niz.gif`), управляя свойствами `background-repeat` и `background-position` без схлопывания внешних отступов (`margin: 0;`).
* **Валидация:** Полное отсутствие ошибок и предупреждений при проверке кода в W3C Validator.
* **История разработки:** Наличие не менее 4–5 осмысленных коммитов, сделанных из среды разработки VS Code в процессе выполнения задачи.
